# 🍿 КиноПоиск На Минималках — Твой Личный Стриминг

Полноценное веб-приложение на фреймворке **Django (Python)** для ведения персонального дневника киномана и совместного наполнения каталога фильмов. Проект разработан с акцентом на чистую бэкенд-архитектуру и удобный интерфейс.

## 🚀 Основные возможности приложения
* **Личные дневники и общие рекомендации:** Пользователи ведут свои независимые списки, но могут отправлять заявки админу на добавление лучших картин в общий каталог.
* **Система модерации контента:** Встроена бэкенд-логика проверки предложенных фильмов. Обычный пользователь отправляет заявку, а администратор одобряет её в один клик.
* **Умный трекинг сериалов:** Для многосерийных проектов база данных позволяет гибко указывать текущий сезон и серию, на которых остановился пользователь.
* **Интеграция с видеоплеерами (RuTube):** Возможность привязывать уникальные бесплатные ссылки к фильмам или к каждому сезону отдельно. Если ссылки нет — Django автоматически сгенерирует поисковый запрос на RuTube под нужный сезон!
* **Динамический интерфейс и постеры:** Поддержка загрузки файлов обложек с компьютера или по URL-ссылкам. Формы админки динамически скрывают и показывают поля в зависимости от типа контента (Фильм/Сериал).
* **Автоматическое наполнение базы:** При первом старте система сама создаёт каталог из 24 популярных киножанров (от Комедии до Киберпанка).

## 🛠️ Технологический стек
* **Язык разработки:** Python 3.12
* **Фреймворк:** Django 5.1 (с использованием Django Admin, Forms, ORM, Signals)
* **База данных:** SQLite 3 (реляционная структура)
* **Работа с медиа:** Библиотека Pillow (валидация и обработка изображений)
* **Контроль версий:** Git & GitHub

## 📂 Структура базы данных (ORM Модели)
1. `User` — встроенная модель Django для авторизации и разделения прав доступа.
2. `Movie` — основная таблица фильмов, сериалов и прогресса просмотра.
3. `Genre` — связанная таблица жанров (связь *Many-to-Many* с фильмами).
4. `Season` — связанная таблица уникальных ссылок на конкретные сезоны (связь *One-to-Many* с сериалами).
